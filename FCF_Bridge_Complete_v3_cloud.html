Прямой метод по отчёту о платежах (ОП)

Сверка с косвенным методом по факту денежных потоков между ЮЛ — раздел показывает, что уже собрано, а что нет.
ОП ЮЛ и ОП Управленка — сверяются с колонками «МСФО» и «Управленческая» косвенного метода выше. Прямой метод не начат по большей части строк — данные ниже частично демонстрационные.
Готово В работе Не начато Статус — на уровне каждой ячейки. Ebitda/NOPAT/FCF считаются автоматически по компонентам.

Дорожная карта трансформации

критический путь инициатива оранжевый текст в поле — владелец не назначен

Реестр инициатив ✓ Сохранено

группировка — строго по разделу (workstream) инициативы, порядок внутри раздела — по номеру id инициативы (2.1, 2.2, ... — не меняется при правке дат) · «Сохранить» фиксирует изменения в общем облачном хранилище (Firebase) — видно всем, кто открывает эту ссылку, даже если ваш ноутбук выключен · «Скачать файл» в карточке Гантта выше — опциональная локальная резервная копия, не единственный способ сохранить данные
